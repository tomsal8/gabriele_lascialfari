# gabriele_lascialfari

Sito vetrina responsive del Geom. Gabriele Lascialfari.

## Struttura

- `index.html`: home e presentazione
- `servizi.html`: approfondimento dei servizi
- `contatti.html`: recapiti e primo contatto
- `style.css`: design system e layout responsive
- `script.js`: menu mobile, animazioni, parallax e barra di avanzamento

Il progetto non richiede build o dipendenze: può essere pubblicato come sito statico.
